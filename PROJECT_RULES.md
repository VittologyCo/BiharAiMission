# Bihar AI Mission Experience Rules

## Purpose
Every animation must reinforce the mission of AI education in Bihar.

## Visual Language
- Calm
- Premium
- Educational
- Human-centered
- No cyberpunk
- No random particles
- No decorative effects without meaning

## Technical Rules
- React + TypeScript only
- GSAP for timelines
- Canvas for particles
- React Three Fiber only where true 3D is needed
- Components must be reusable
- Strict TypeScript
- Performance first

## Interaction Rules
- Every click has purpose
- Every hover provides feedback
- Animations must be interruptible
- Respect prefers-reduced-motion

## Code Quality
- No files over ~300 lines where practical
- One responsibility per component
- Reusable hooks and utilities
- Document complex animation logic
